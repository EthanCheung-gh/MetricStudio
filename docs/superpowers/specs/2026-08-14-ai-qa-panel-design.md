# AI 问答面板设计规范

> 对话式提问当前数据集，LLM 基于注入的真实数据上下文回答
> 日期: 2026-08-14 · 状态: 已批准

## 1. 目标

用户对当前数据集提问（"哪个地区销售额最高？"），LLM 基于后端注入的真实数据摘要回答，而非凭空生成（防幻觉）。

## 2. 后端

`POST /api/v1/nl/ask` `{dataset_id, question}` → `{answer}`

- 组装数据上下文：列 schema + 数值列统计 + 前 5 行样本 + insights 摘要
- prompt 要求「只基于提供的数据回答，引用具体数字」
- 复用 `llm.chat`

## 3. 前端

`AskPanel`：单轮问答（问题 → 答案），答案多行展示，保留本轮问答历史。

## 4. 测试（mock LLM）

- prompt 含数据上下文（列名/样本）
- 端点返回 answer
- LLM 不可用 502

## 5. 非目标

- 多轮对话历史持久化（后续）
- 答案结构化/图表联动
